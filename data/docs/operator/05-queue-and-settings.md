# Очередь, настройки и уведомления

## Разделы списка талонов

- **Ожидающие** — талоны, которые ещё не вызваны.
- **Отложенные** — клиенты, временно отложенные вами и закреплённые за вашим местом.
- **Отменённые** — талоны, обслуживание которых прекращено.
- **Обслуженные** — завершённые вами талоны за текущий рабочий период.

Число рядом с названием раздела показывает количество талонов. Нажмите на название, чтобы открыть список.

## Автовызов

Если автовызов включён, система сама назначит следующего подходящего клиента после установленной задержки. Текущее состояние автовызова показывается в рабочей области.

Автовызов может быть отключён общей настройкой или персонально для вашего аккаунта. При низкой нагрузке система также может распределять клиентов между свободными операторами, а не назначать их одному за другим одному сотруднику.

## Настройки оператора

Нажмите **«Настройки»** в верхней части экрана. Здесь можно:

- включить или выключить звук при появлении нового талона;
- разрешить системные уведомления браузера;
- показать или скрыть кнопки «Вызвать по номеру»;
- открыть эту инструкцию;
- прочитать список обновлений.

Для системных уведомлений браузер может отдельно запросить разрешение. Если уведомления ранее были запрещены в браузере, одной кнопки в очереди недостаточно — разрешение нужно изменить в настройках сайта.

## Обновления

После изменений в работе очереди система может показать обязательное сообщение. Прочитайте его полностью и подтвердите ознакомление. Позже историю можно открыть через **«Настройки» → «Обновления»**.
